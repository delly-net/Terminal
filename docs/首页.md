## 项目概述

Delly.Terminal 是一个 C# 类库，提供灵活的终端组件，支持实时输出监控和进程树管理。允许开发者轻松执行外部命令行程序，并实时捕获其输出。

## 主要特性

- 同步和异步命令执行模式
- 实时输出事件监听（标准输出和错误输出）
- 进程树管理（Windows 平台）
- 字符编码处理（UTF-8）
- .NET Standard 2.0 和 .NET 6.0 多平台支持
