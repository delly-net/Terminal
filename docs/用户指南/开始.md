# 开始使用 Delly.Terminal

## 安装

```bash
dotnet add package Delly.Terminal
```

## 快速开始

### 同步执行命令

```csharp
using Delly.Terminal;

var runner = new Runner("cmd", "/c dir");
string output = runner.Run();
Console.WriteLine(output);
```

### 异步执行命令

```csharp
using Delly.Terminal;

var runner = new Runner("cmd", "/c dir");
runner.Start();

// 订阅输出事件
runner.OutputLine += (sender, e) => {
    Console.WriteLine($"Output: {e.Content}");
};

runner.ErrorLine += (sender, e) => {
    Console.WriteLine($"Error: {e.Content}");
};
```

### 指定工作目录

```csharp
var runner = new Runner("cmd", "/c dir", "C:\\Windows");
string output = runner.Run();
```

### 指定编码

```csharp
var runner = new Runner("cmd", "/c dir", null, "UTF-8");
string output = runner.Run();
```

## API 参考

### Runner 类

| 方法 | 说明 |
|:---|:---|
| `Run()` | 同步执行命令并返回完整输出 |
| `Start()` | 启动命令（异步模式） |
| `Close()` | 关闭程序 |
| `Kill()` | 终止进程及其子进程树 |
| `Dispose()` | 释放资源 |

### 事件

| 事件 | 说明 |
|:---|:---|
| `OutputLine` | 标准输出行事件 |
| `ErrorLine` | 错误输出行事件 |

### 属性

| 属性 | 说明 |
|:---|:---|
| `IsRunning` | 是否运行中 |
| `Command` | 命令字符串 |
| `Outputs` | 输出内容列表 |
| `Errors` | 错误内容列表 |
| `Input` | 输入流 |
