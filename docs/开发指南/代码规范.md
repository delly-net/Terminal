# 代码规范

## C# 代码风格

### 命名约定

- **类名**: PascalCase（如 `Runner`, `CommandException`）
- **方法名**: PascalCase（如 `Run()`, `Start()`, `Kill()`）
- **属性名**: PascalCase（如 `IsRunning`, `Command`）
- **字段名**: camelCase，私有字段加下划线前缀（如 `_process`, `_output`）
- **常量**: PascalCase（如 `NORMAL_CHARS`, `CHAR_ENTER`）

### 文件组织

- 每个类一个文件，文件名与类名一致
- 相关类放在同一命名空间下的子目录中
  - `Event/` - 事件相关类
  - `Exception/` - 异常相关类

### .NET Standard 2.0 兼容性

使用条件编译保持多框架兼容：

```csharp
#if NETSTANDARD2_0
    private StreamReader _output = null;
#else
    private StreamReader? _output = null;
#endif
```

### 注释规范

- 公共 API 使用 XML 文档注释
- 注释使用中文
- 保持简洁，描述"为什么"而不是"做什么"

### 线程安全

- 共享静态资源使用 `lock` 保护
- 事件处理注意避免内存泄漏

### 资源管理

- 实现 `IDisposable` 接口
- 在 `Dispose()` 中正确释放资源（StreamReader, StreamWriter, Process）
- 使用 null 条件操作符检查非空引用
