# 1.2 补全项目包信息

## 任务概述

完善 `Delly.Terminal.csproj` 项目的 NuGet 包信息，确保发布的 NuGet 包包含完整的元数据信息。

## 任务类型

信息生成

## NuGet 包元数据配置

根据已确认的需求，NuGet 包元数据配置如下：

| 配置项 | 值 |
|:------|:---|
| **PackageId** | `Delly.Terminal` |
| **Version** | 继承项目版本号（需确定映射规则） |
| **Authors** | `Delly.Net` |
| **Company** | 空（个人项目） |
| **Description** | 基于 `CLAUDE.md` 项目概述生成 |
| **PackageTags** | `terminal, process, csharp, command, stdout, stderr` |
| **RepositoryUrl** | `https://github.com/delly-net/Terminal` |
| **LicenseExpression** | `MIT` |
| **ProjectUrl** | `https://github.com/delly-net/Terminal`（可选，同仓库地址） |

## 代码规范

### 命名约定

- PackageId 使用 PascalCase ✓
- 标签使用小写，用逗号分隔 ✓
- 描述使用简体中文 ✓

## 实现要求

### 功能流程

1. **读取现有项目文件**
   - 读取 `Delly.Terminal/Delly.Terminal.csproj`
   - 分析现有的 NuGet 包信息配置

2. **添加/更新 NuGet 元数据**
   ```xml
   <PropertyGroup>
     <PackageId>Delly.Terminal</PackageId>
     <Version><!-- 继承项目版本号 --></Version>
     <Authors>Delly.Net</Authors>
     <Company></Company>
     <Description>Delly.Terminal 是一个灵活的终端组件类库，支持实时输出监控和进程树管理。</Description>
     <PackageTags>terminal, process, csharp, command, stdout, stderr</PackageTags>
     <RepositoryUrl>https://github.com/delly-net/Terminal</RepositoryUrl>
     <LicenseExpression>MIT</LicenseExpression>
     <ProjectUrl>https://github.com/delly-net/Terminal</ProjectUrl>
   </PropertyGroup>
   ```

3. **保持多目标框架**
   - 确保保留 `TargetFrameworks` 为 `netstandard2.0;net6.0`

### 输出规范

更新后的 `Delly.Terminal.csproj` 文件应包含完整的 NuGet 包元数据，格式符合 NuGet 规范。

### 包描述（基于项目概述）

> Delly.Terminal 是一个灵活的终端组件类库，提供外部进程运行、实时输出监控和进程树管理功能。支持 .NET Standard 2.0 和 .NET 6.0 多目标框架，适用于跨平台开发。
