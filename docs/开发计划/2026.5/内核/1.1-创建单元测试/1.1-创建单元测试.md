# 1.1 创建单元测试

## 任务概述

针对 `Runner.cs` 中的所有公共方法和属性建立单元测试，使用 xUnit 测试框架，原生断言，目标代码覆盖率达到 90%。

## 任务类型

代码测试

## 代码规范

### 命名约定

- 测试项目名：`UnitTests.Terminal`
- 测试类名：被测类名 + `Tests`（如 `RunnerTests`）
- 测试方法名：`[方法名]_[场景]_[预期结果]`（如 `Run_ValidCommand_ReturnsOutput`）
- 测试数据：使用描述性名称

### 文件组织

测试项目结构：
```
UnitTests.Terminal/
├─ UnitTests.Terminal.csproj
├─ RunnerTests.cs
├─ Event/
│  └─ CommandOutputLineEventArgsTests.cs
└─ Exception/
   └─ CommandExceptionTests.cs
```

### 测试框架配置

- **测试框架**：xUnit
- **Mock 库**：不需要
- **断言方式**：原生断言（Assert.Equal 等）
- **覆盖率目标**：90%
- **覆盖率报告**：生成 HTML 格式报告
- **平台支持**：仅测试当前平台
- **CI/CD 集成**：不需要

## 测试覆盖范围

### 构造函数测试

- `[构造函数(ProcessStartInfo)]` - 验证正确初始化
- `[构造函数(path, arg, workPath, encodingName)]` - 验证参数处理
- `[构造函数(path, arg, workPath)]` - 验证参数传递
- `[构造函数(path, arg)]` - 验证参数传递
- `[构造函数(path)]` - 验证简单构造

### 属性测试

- `Input` - 验证输入流访问
- `Outputs` - 验证输出列表访问
- `Errors` - 验证错误列表访问
- `IsRunning` - 验证运行状态
- `Command` - 验证命令字符串生成

### 方法测试

- `Run()` - 验证同步执行
- `Start()` - 验证异步启动
- `Close()` - 验证进程关闭
- `Kill()` - 验证进程树终止（Windows 平台）
- `Dispose()` - 验证资源释放

### 事件测试

- `OutputLine` - 验证输出事件触发
- `ErrorLine` - 验证错误事件触发

## 测试场景

### 正常流程测试

1. **命令执行成功**
   - 执行简单命令（如 `echo`）
   - 验证输出正确捕获
   - 验证错误列表为空

2. **命令执行失败**
   - 执行无效命令
   - 验证捕获错误输出
   - 验证异常抛出

3. **工作目录设置**
   - 设置工作目录
   - 验证命令在正确目录执行

4. **编码设置**
   - 设置 UTF-8 编码
   - 验证中文字符正确处理

### 异常测试

1. **无效命令路径**
   - 传入不存在的程序路径
   - 验证 `CommandException` 抛出

2. **参数为空**
   - 验证 null 参数处理（.NET 6.0+）
   - 验证空字符串处理

3. **资源释放测试**
   - 验证 `Dispose()` 正确释放资源
   - 验证多次调用 `Dispose()` 不报错

### 边界测试

1. **大量输出**
   - 执行产生大量输出的命令
   - 验证所有输出都被正确捕获

2. **特殊字符处理**
   - 验证 Tab、换行、控制字符处理
   - 验证 Unicode 字符处理

3. **进程树终止**
   - 启动有子进程的命令
   - 验证 `Kill()` 终止所有子进程
   - **非 Windows 平台跳过此测试**

## 项目配置

### 单元测试项目

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFrameworks>netstandard2.0;net6.0</TargetFrameworks>
    <IsPackable>false</IsPackable>
  </PropertyGroup>

  <ItemGroup>
    <PackageReference Include="xunit" Version="2.6.6" />
    <PackageReference Include="xunit.runner.visualstudio" Version="2.5.6">
      <IncludeAssets>runtime; build; native; contentfiles; analyzers; buildtransitive</IncludeAssets>
      <PrivateAssets>all</PrivateAssets>
    </PackageReference>
    <PackageReference Include="Microsoft.NET.Test.Sdk" Version="17.9.0" />
    <PackageReference Include="coverlet.collector" Version="6.0.2">
      <IncludeAssets>runtime; build; native; contentfiles; analyzers; buildtransitive</IncludeAssets>
      <PrivateAssets>all</PrivateAssets>
    </PackageReference>
  </ItemGroup>

  <ItemGroup>
    <ProjectReference Include="..\Delly.Terminal\Delly.Terminal.csproj" />
  </ItemGroup>
</Project>
```

## 实现要求

### 功能流程

1. **项目创建**
   - 创建 UnitTests.Terminal 项目
   - 引用 Delly.Terminal 项目
   - 配置 xUnit 和覆盖率工具

2. **测试编写**
   - 按照 Arrange-Act-Assert (AAA) 模式组织测试
   - 每个测试方法独立，不依赖其他测试
   - 使用平台特性标记跳过非 Windows 平台的进程树测试

3. **覆盖率验证**
   - 运行测试并生成覆盖率报告
   - 验证覆盖率达到 90%

### 输出规范

1. **测试项目文件**
   - `UnitTests.Terminal.csproj` - 项目配置

2. **测试文件**
   - `RunnerTests.cs` - Runner 类的测试
   - `Event/CommandOutputLineEventArgsTests.cs` - 事件参数类测试
   - `Exception/CommandExceptionTests.cs` - 异常类测试

3. **覆盖率报告**
   - HTML 格式的覆盖率报告
   - 覆盖率需达到 90%
