3. **项目结构**：测试项目命名为 UnitTests.Terminal
4. **报告生成**：需要配置 HTML 覆盖率报告工具（如 ReportGenerator）
5. **平台兼容性**：非 Windows 平台跳过进程树测试，使用平台特性标记
