# 1.1 创建单元测试

## 任务概述

针对 `Runner.cs` 中的所有公共方法和属性建立单元测试。

## 代码规范

### 命名约定

- 测试类名：被测类名 + `Tests`（如 `RunnerTests`）
- 测试方法名：`[方法名]_[场景]_[预期结果]`（如 `Run_ValidCommand_ReturnsOutput`）
- 测试数据：使用描述性名称

### 文件组织

- 测试项目结构：
  ```
  Delly.Terminal.Tests/
  ├─ RunnerTests.cs
  ├─ Event/
  │  └─ CommandOutputLineEventArgsTests.cs
  └─ Exception/
     └─ CommandExceptionTests.cs
  ```

### 测试框架

- 使用 xUnit 或 NUnit 测试框架
- 使用 Moq 进行模拟（如需要）
- 使用 FluentAssertions 进行断言

### 测试覆盖

#### 构造函数测试

- `[构造函数(ProcessStartInfo)]` - 验证正确初始化
- `[构造函数(path, arg, workPath, encodingName)]` - 验证参数处理
- `[构造函数(path, arg, workPath)]` - 验证参数传递
- `[构造函数(path, arg)]` - 验证参数传递
- `[构造函数(path)]` - 验证简单构造

#### 属性测试

- `Input` - 验证输入流访问
- `Outputs` - 验证输出列表访问
- `Errors` - 验证错误列表访问
- `IsRunning` - 验证运行状态
- `Command` - 验证命令字符串生成

#### 方法测试

- `Run()` - 验证同步执行
- `Start()` - 验证异步启动
- `Close()` - 验证进程关闭
- `Kill()` - 验证进程树终止
- `Dispose()` - 验证资源释放

#### 事件测试

- `OutputLine` - 验证输出事件触发
- `ErrorLine` - 验证错误事件触发

### 测试场景

#### 正常流程测试

1. **命令执行成功**
   - 执行简单命令（如 `echo`）
   - 验证输出正确捕获
   - 验证错误列表为空

2. **命令执行失败**
   - 执行无效命令
   - 验证捕获错误输出
   - 验证异常抛出

3. **工作目录设置**
   - 设置工作目录
   - 验证命令在正确目录执行

4. **编码设置**
   - 设置 UTF-8 编码
   - 验证中文字符正确处理

#### 异常测试

1. **无效命令路径**
   - 传入不存在的程序路径
   - 验证 `CommandException` 抛出

2. **参数为空**
   - 验证 null 参数处理（.NET 6.0+）
   - 验证空字符串处理

3. **资源释放测试**
   - 验证 `Dispose()` 正确释放资源
   - 验证多次调用 `Dispose()` 不报错

#### 边界测试

1. **大量输出**
   - 执行产生大量输出的命令
   - 验证所有输出都被正确捕获

2. **特殊字符处理**
   - 验证 Tab、换行、控制字符处理
   - 验证 Unicode 字符处理

3. **进程树终止**
   - 启动有子进程的命令
   - 验证 `Kill()` 终止所有子进程（Windows）
